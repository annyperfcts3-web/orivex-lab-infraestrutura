
# ORIVEX LAB — Infraestrutura, Redes e Cloud Computing

Laboratório de estudos, documentação técnica e práticas aplicadas à infraestrutura de TI, redes, Linux, monitoramento, segurança, automação e computação em nuvem.

## Sobre o projeto

O **ORIVEX LAB** é um projeto de desenvolvimento técnico voltado à consolidação de conhecimentos em infraestrutura de TI, administração de redes, sistemas operacionais, monitoramento e serviços em nuvem.

O objetivo é documentar conceitos, executar laboratórios práticos e desenvolver competências relacionadas a ambientes corporativos, telecomunicações e operações NOC.

## Objetivos

- Documentar conceitos de redes e infraestrutura.
- Desenvolver conhecimentos em administração Linux e Windows.
- Estudar monitoramento e disponibilidade de serviços.
- Aplicar fundamentos de segurança da informação.
- Conhecer automação de infraestrutura com Python.
- Praticar serviços de computação em nuvem AWS.
- Desenvolver conhecimentos relacionados a operações NOC e ambientes FTTH.

## Estrutura do laboratório

| Diretório | Conteúdo |

## Cloud Computing — Laboratórios AWS

Práticas realizadas na Amazon Web Services (AWS), utilizando serviços de infraestrutura em nuvem.

### Laboratório 01 — Amazon EC2

- Conhecimento do serviço Amazon EC2.
- Criação de máquina virtual Linux.
- Utilização do Amazon Linux 2023.
- Instalação e configuração do servidor web Nginx.
- Verificação do serviço HTTP e da porta 80.

Arquivo: `06-nuvem/laboratorios/01-primeira-maquina-virtual-aws.md`

### Laboratório 02 — Amazon VPC

- Identificação de uma Virtual Private Cloud.
- Análise de endereçamento IPv4 e CIDR.
- Identificação de sub-redes em diferentes zonas de disponibilidade.
- Análise de tabela de rotas.
- Identificação de Internet Gateway.
- Verificação de Network ACL e Security Groups.

Arquivo: `06-nuvem/laboratorios/02-rede-virtual-aws.md`

### Laboratório 03 — Amazon S3

- Criação de bucket.
- Configuração de acesso privado.
- Bloqueio de acesso público.
- Criptografia padrão SSE-S3.
- Upload de arquivo.
- Verificação de objeto e permissões de acesso.

Arquivo: `06-nuvem/laboratorios/03-armazenamento-em-nuvem.md`

### Laboratório 04 — Amazon CloudWatch

- Acesso ao serviço CloudWatch.
- Identificação de métricas da instância EC2.
- Consulta de CPUUtilization.
- Identificação de DiskReadBytes e DiskReadOps.
- Análise da disponibilidade de métricas.

Arquivo: `06-nuvem/laboratorios/04-monitoramento-aws.md`
