
# Comandos Linux — Navegação em Diretórios

## 1. Objetivo

Documentar os principais comandos utilizados para navegar e consultar a estrutura de diretórios do Linux.

## 2. Comando PWD

Significado: Print Working Directory.

Finalidade: exibir o caminho completo do diretório atual.

Sintaxe:

pwd

Exemplo de saída:

/home/usuario

Aplicação: identificar a localização atual no sistema de arquivos.

## 3. Comando LS

Significado: List.

Finalidade: listar arquivos e diretórios.

Principais opções:

| Comando | Finalidade |
|---|---|
| ls | Lista arquivos e diretórios |
| ls -l | Exibe informações detalhadas |
| ls -a | Exibe arquivos ocultos |
| ls -lh | Exibe tamanhos em formato legível |
| ls -la | Lista detalhada, incluindo ocultos |

Aplicação: consultar o conteúdo dos diretórios.

## 4. Comando CD

Significado: Change Directory.

Finalidade: navegar entre diretórios do sistema.

Exemplos:

cd /etc

Acessa o diretório /etc.

cd /var/log

Acessa o diretório de registros do sistema.

cd ..

Retorna ao diretório anterior na hierarquia.

cd ~

Acessa o diretório pessoal do usuário.

cd /

Acessa o diretório raiz.

## 5. Aplicação em infraestrutura

Os comandos PWD, LS e CD são utilizados na navegação pelo sistema de arquivos Linux, permitindo localizar diretórios, consultar arquivos e acessar caminhos necessários à administração de servidores.

## 6. Conclusão

O conhecimento desses comandos representa a base para a utilização do terminal Linux e para atividades de administração de sistemas e infraestrutura.
