
# Estrutura de Diretórios Linux

## 1. Objetivo

Compreender a hierarquia de diretórios do Linux e identificar a finalidade dos principais caminhos utilizados na administração de sistemas.

## 2. Hierarquia

A estrutura de diretórios Linux possui uma organização hierárquica iniciada pelo diretório raiz (/).

## 3. Principais diretórios

| Diretório | Finalidade |
|---|---|
| / | Raiz do sistema |
| /etc | Arquivos de configuração |
| /var | Dados variáveis |
| /var/log | Arquivos de log |
| /home | Diretórios dos usuários |
| /root | Diretório pessoal do administrador |
| /tmp | Arquivos temporários |
| /usr | Aplicações e recursos |
| /bin | Comandos essenciais |
| /sbin | Ferramentas administrativas |
| /boot | Arquivos de inicialização |
| /dev | Arquivos de dispositivos |
| /proc | Informações de processos e kernel |
| /mnt | Pontos de montagem |
| /media | Mídias removíveis |

## 4. Aplicação em infraestrutura

O conhecimento da estrutura de diretórios permite localizar arquivos de configuração, analisar logs, investigar processos e administrar recursos de servidores Linux.

## 5. Conclusão

A compreensão da hierarquia de diretórios é fundamental para atividades de administração Linux, suporte de infraestrutura e troubleshooting.
